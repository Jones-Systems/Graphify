## 2. Architecture recommendation (exact tools + versions for this host)

Two planes share one graphifyy-compatible node-link JSON spine feeding the existing S-A gated 3-way RRF + bge-reranker-base fusion unchanged. PLANE A — deterministic enrichment (day one, no LLM): person/org mention tables out of graphifyy exports → multi-pass RapidFuzz 3.14.x blocking (token-sort keys ∥ capped trigram inverted index ∥ SNM w=10 ∥ jellyfish==1.2.1 metaphone; cap blocks >500) → single process.cpdist(JaroWinkler, score_cutoff≈0.85, workers=-1, dtype=uint8) verification → union-find clusters → splink==4.0.16 Fellegi-Sunter EM scoring (DuckDBAPI memory_limit≤2.5GiB) → canonical_entity_id plus confidence assertions appended to a PG17 entity_identifier log (live-row partial unique indexes; nomenklatura==4.13.0 match_proposal queue). In parallel per language repo: scip-python 0.6.6 / rust-analyzer `scip` / scip-typescript 0.4.0 → pinned scip CLI v0.9.0 print --json → stdlib converter emitting def/ref/implements edges; tree-sitter>=0.25.2,<0.27 + tree-sitter-language-pack~=1.13.5 tags.scm harvesting covers bash/yaml/json/markdown-injections (Swift only if corpus exists); grimp==3.15 + dependency-cruiser==18.2.0 emit true import direction for PPR. Quarterly: aria2c Wikidata CC0 dump (~100–160 GB compressed; validate .sha1; dumps server caps 3 conn/IP) → wdgrep type-closure carve (Q5/Q43229*/Q7397) → QLever subset SPARQL index + tantivy label/aliases index + QRank priors; anchor by exact P1324/P856/P496 matches first, EventStreams marks stale QIDs nightly. PLANE B — governed local-LLM extraction (owner-scheduled nights): GLiNER2.5-base proposes spans and gates every call; llama-server v0.3.0/b10621 (-t 16 -np 4 -c 16384 -fa on -ctk/-ctv q8_0 --load-mode mmap+mlock --numa distribute --metrics, loopback + --api-key) serves Qwen3-4B-Instruct-2507 Q5_K_M (~2.69 GiB; ladder to Qwen3-8B Q4_K_M only after on-host llama-bench + scripts/server-bench.py -np 4 prove ≥12 t/s and ≥6.5 GiB headroom); response_format=json_schema flat Draft-2020-12 schemas, instructor-style validate-retry ≤2×, two-pass reason-then-format on hard tasks; turnkey alternative: ollama v0.32.15 stable, OLLAMA_NUM_PARALLEL=1 OLLAMA_MAX_LOADED_MODELS=1 OLLAMA_FLASH_ATTENTION=1 OLLAMA_KV_CACHE_TYPE=q8_0, models pulled by manifest digest @sha256. Everything runs inside enrich-model.slice (MemoryHigh=8G/MemoryMax=11G, CPUQuota=1150%, Nice=10) behind the MemAvailable+PSI governor (pause <4096 MiB, resume >6144 MiB, PSI trigger "some 150000 1000000") with SQLite WAL lease-ledger resume; nightly timer phases unload the model (keep_alive=0) before tantivy/sqlite-vec/Splink phases. All CPU-only, offline, MIT/Apache/BSD except flagged items; nothing breaches the 3072 MiB floor outside governed slices.

## 4. Cross-theme synergies

- T4×T6: GLiNER spans both gate LLM relation calls and seed RapidFuzz/Splink candidates; published evidence shows output format dominates generative NER (inline ≫ offset JSON, arXiv 2601.17898) so entities stay encoder-side while the LLM proposes relations only (recs 4×9×3).
- Splink cluster output IS governance input: clusters land as assertions (confidence ladder, artifact_ref=splink run id) in entity_identifier; nomenklatura queue owns gray-band adjudication; the eval gate promotes threshold changes (recs 1×5×6).
- T5×T4 identity symmetry: SCIP global symbol strings play exactly the role for code entities that (namespace,value) pairs play for people/orgs — one xref machinery, one partial-unique-index integrity story, cross-repo joins for both (recs 2×5).
- Wikidata anchors close Splink's documented weak spot (single-column org names unsupported): exact P1324/P856/P496 matches resolve software/orgs deterministically; GLiNER/vector similarity handles residue (recs 7×1×4).
- One promotion pipeline serves all three themes: frozen-label + Wilson-LB + paired cluster-bootstrap gating validates Splink config changes, GLiNER thresholds, constrained-vs-unconstrained LLM A/B, and quant downgrades (Q4_K_M golden-set KLD<0.02 + span-F1 gate) (rec 6 universal).
- Blocking doctrine transfers theme-free: count comparisons before running and cap blocks — applies equally to Splink rules and trigram postings (recs 3×1).
- Downstream fusion payoff: canonical entity nodes (less fragmentation) + compiler-grade def/ref edges + true import direction all feed S-A's gated 3-way RRF/PPR-over-KG as better seeds and typed edge kinds — zero rework of phase-1 ranking (all).
- The governor protects everything, not just LLMs: MemAvailable+PSI hysteresis wraps Splink DuckDB bursts, SCIP indexing, and decode alike — one enforcement mechanism program-wide (rec 10).
- ReLiK joint entity linking emits mention→QID pairs consumable by both Splink validation and Wikidata anchoring (recs 9×7).
- Quant × RAM math composes: KV q8_0 + Q5_K_M keeps an 8B deployment ≈7–8 GiB total — inside governor ceilings with no scheduling gymnastics (recs 9×10).
