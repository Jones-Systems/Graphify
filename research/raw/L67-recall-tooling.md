VERDICT: Top pick is ranx (MIT, CPU-only) as primary harness inside a thin custom layer: persist every stack variant as a TREC run file → `ranx.evaluate(qrels, run, ['recall@10','recall@100'])` for Recall@k tables → `ranx.compare(qrels, runs, metrics, max_p=0.05)` for Fisher-randomization significance reports → `ranx.optimize_fusion([bm25_run, dense_run, ppr_run], norm='min-max', method='wsum', metric='recall@100')` on a dev split to tune the gated 3-way RRF before promoting. Integration: (1) dump top-1000 per variant from tantivy/sqlite-vec/PPR to runs/*.tsv; (2) `pip install ranx` (few hundred MB peak RAM at our judgment volumes — inside the 3072 MiB floor); (3) wire compare() into nightly CI as a promotion gate failing on significant fused Recall@10 regressions. Skip pyserini and beir-lib as harnesses: neither provides significance testing and both import heavy foreign retrieval stacks; reconsider beir only if we adopt public benchmark collections.
