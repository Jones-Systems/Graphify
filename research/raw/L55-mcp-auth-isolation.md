# LANE L55 - T8 MCP: auth/isolation model for one shared local graph-query MCP server hit by many concurrent agent sessions
Research date: 2026-08-25. Target constraints: CPU-only, available-memory floor 3072 MiB, Python 3.13, offline/self-hosted. No item requires an external API key.

Protocol context: MCP spec 2025-06-18 lets servers omit Mcp-Session-Id (stateless mode); released 2026-07-28 spec removes initialize handshake and Mcp-Session-Id entirely (stateless by default, state moves to app-level handles) per modelcontextprotocol.io/specification/2025-06-18/basic/transports and blog.modelcontextprotocol.io/posts/2026-07-28-release-candidate/. Authorization section makes servers OAuth 2.1 resource servers that must validate RFC 8707 audience binding and must not pass tokens through (modelcontextprotocol.io/specification/2025-06-18/basic/authorization).

Verdict: top pick is layered localhost stack around FastMCP (Apache-2.0): stateless Streamable HTTP on 127.0.0.1; launcher mints one opaque bearer token per agent session via StaticTokenVerifier so rate limiting (get_client_id=sub), daily query budget, UserSession namespaces, and audit logs all key on unforgeable identity; corpus opened strictly read-only (sqlite OPEN_READONLY+authorizer SELECT-only; kuzu read_only+set_query_timeout) with per-sub scratch namespaces for writes; whole process wrapped in systemd unit MemoryMax~4G/CPUQuota/DynamicUser/ProtectSystem=strict as final blast-radius wall protecting the declared memory floor. Defer full OAuth/RFC 8707 and agentgateway until the server leaves loopback or multiplexes upstreams; skip Docker gateway and UDS for now.

Integration sketch for the target stack: graph-query-mcp = FastMCP HTTP app exposing read tools kg_search, ppr_fuse, bm25_search, vec_search, rerank plus scratch_write; opens shared sqlite/kuzu store read-only at startup; middleware chain ErrorHandling -> AuthN(StaticTokenVerifier) -> RateLimit(sub) -> Budget(sub) -> Logging(JSON) -> ResponseLimit(500KB); tokens delivered by session launcher via env var; launched under hardened systemd unit. All offline, no GPU.
