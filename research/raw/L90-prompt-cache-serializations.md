## Verdict
Top pick: fold items 1+4+5 into ONE deterministic serializer module — schema-fixed field order per kind, scores rounded (≥3dp) or tiered before sort+emit, rows grouped by kind and sorted by stable ID, query parameters/meta LAST, no timestamps inside the body — because every cache examined (OpenAI 128-tok blocks, Anthropic breakpoints, vLLM/SGLang blocks/pages) matches exact tokenized prefixes, so byte-stability across similar queries is the sole lever converting misses into 90%-discounted reads.
Integration sketch: in the search service, route fused graphifyy/BM25/vec output through `render_context()` emitting `[static schema preamble → cache_control breakpoint][result rows, (kind,id)-ordered, quantized scores][volatile meta]`; set `prompt_cache_key` (OpenAI) / system-block `cache_control` (Anthropic) at the call site; log cached-token counters per query shape and alert on hit-rate drops. TOON (#10) is a cheap follow-on experiment at the LLM boundary only if our tokenizer confirms wins vs compact JSON.
