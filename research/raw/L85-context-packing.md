**Verdict (top pick):** Composite recipe — HippoRAG2-style seeding (#3) + G-Retriever prize-minus-cost truncation (#4) + tiktoken ledger (#12), dressed with GraphRAG class-proportions (#1) and lost-in-the-middle ordering (#11). Why: zero new services/GPU/cloud, everything MIT/Apache, and the evidence base shows 40–99% token reductions without quality loss while fixing position bias.
**Integration sketch:** seed existing PPR personalization from gated 3-way RRF hits (BM25+sqlite-vec+entity match) → greedily grow neighborhood while prize(node) > λ·C_e until ledger cap (λ tuned per query so Σtokens ≤ pool) → split packed pool ≈50% tantivy source snippets / 15% summary nodes / 35% entity-edge lines → rerank survivors with bge-reranker-v2-m3 ONNX-int8 (≤50 cands) → serialize ascending score (best last), dedup parent/child spans, final tiktoken assert on assembled string.
