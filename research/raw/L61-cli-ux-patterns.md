## Verdict (≤3 lines)
Top pick: ship ONE "agent contract" bundle — NDJSON `{type,data}` event streams (row 1) + `--json FIELDS --jq` selection (row 6) + rg exit codes/determinism (row 10) — implemented in the existing stdlib argparse/JSON style; humans get fzf-preview (row 3) and mermaid/dot renderers (row 7) layered on the same verbs.
Integration sketch: add shared `codex_v3/graphio.py` (record dataclasses → envelope emitter → per-render sinks); every graph verb gains `--render/--json/--color/--sort/--max-*` flags with TTY-gated defaults; wrap interactive entry `gnav ui` = fzf pipeline guarded by `sys.stdout.isatty()`; Textual explorer later behind `[project.optional-dependencies] tui = ["textual>=8"]`.
Why: identical verbs serve both audiences (agents parse events; humans get previews of the same commands), zero required deps, everything offline/MIT-compatible, and each piece is independently revertible.
