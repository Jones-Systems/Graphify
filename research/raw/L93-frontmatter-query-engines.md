**Verdict:** Top pick = python-frontmatter 1.3.0 + sqlite-utils 4.2.1: at ingest, parse each md's front-matter once and upsert a flattened `note_meta(repo, path PK, mtime, tags_json, <projected typed cols>)` table INTO THE SAME SQLite file as sqlite-vec, with FTS5 enabled on title/body — giving SQL/range/join queries over front-matter that feed the 3-way RRF gate as pre-filters and PPR node attributes, at AdoptCost 1 with zero new daemons. Best ready-made Dataview-class *query language* headless is mdbasequery (MIT, executes real `.base` expressions/formulas/groupBy over any md dir) if a small Node-sidecar is acceptable; zk v0.15.6 is the strongest single-binary interactive fallback (GPL-3.0 caveat, limited custom-key filtering). Secondary: mirror front-matter into tantivy fast fields (aggregations ≥0.22, FastFieldRangeQuery ≥0.24 — verify the chosen binding) so BM25 and metadata range/facets fuse in one query; skip Datacore/Bases-native/Emanote for now.
