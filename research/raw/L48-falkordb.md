## Verdict
Top pick: FalkorDB v4.20.4 is technically a strong fit for ~200k-node KGs — CPU-only (OpenMP/GraphBLAS), sub-2 GB RAM expected ([INFERENCE] from official 1.5–1.7 KB/node bench), Cypher subset covers PPR-style traversal queries, MIT Python 3.13 client.
The blocker is non-technical: SSPL-1.0 is source-available (excluded from Debian main/Fedora, OSI-rejected) — fine for internal VPS use, flagged `requires-owner-approval` if ever offered as a service; Docker-only deployment adds a second stateful service beside pg17.
Integration sketch: run as opt-in graph store behind a feature flag — `docker run -p 6380:6379 --memory=2g falkordb/falkordb`; bulk-load graphifyy==0.9.16 structural graph via UNWIND batch inserts, index entity keys, serve multi-hop expansion + PPR seed queries from falkordb-py while tantivy/LanceDB stay authoritative; verify with `GRAPH.MEMORY USAGE` under the MemAvailable floor before promotion over the pg17 hybrid route.
