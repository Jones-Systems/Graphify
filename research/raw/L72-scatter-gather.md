## Verdict
Top pick: app-layer WEIGHTED RRF (k=60) fed by a bounded-parallel deadline scatter - asyncio TaskGroup + Semaphore(min(16,N)), per-corpus soft timeout returning partials, uniform oversampled windows max(100, 3*k_final), deterministic-ID dedup before fusion; sequential fan-out rejected (latency sums linearly over 18 corpora), raw score-merge deferred (uncalibrated cross-corpus score spaces; Bruch TOIS24 preconditions absent).
Integration: interim = SQLite ATTACH UNION ALL per-corpus LIMIT windows merged by L17's stdlib fuse; target = fold the same windows into L20's central-PG17 UNION ALL CTEs once the research DB lands (shared stats space then unlocks central-recalculation/score-merge without new infra); add per-index weights + hedges only after measuring per-corpus p95s; ranx reserved for offline fusion experiments.
Elasticsearch RRF (Platinum/Enterprise-gated) and any cloud/API item REQUIRE-OWNER-APPROVAL; Meilisearch/OpenSearch/Milvus engines stay evidence-only (daemon RAM, duplicate indexes, license splits).

## Latency budget model (pending measurement; formulas exact, example numbers [INFERENCE])
- Sequential: E[t] = N * p50; tail = sum_i p95_i. At N=18 even p50=8ms/corpus gives 144ms median and ~450ms worst case - unusable interactively.
- Bounded-parallel B=16: waves = ceil(18/16)=2 -> E[t] ~ p50_best + p50_second-wave; wall-clock tail ~ max_i(p95_i) ~ 25-40ms. Event-loop overhead us/op; memory ~2MB/query burst.
- Policy: soft timeout tau_c = min(0.5*budget, 3*p95_c) per corpus; expired corpus contributes empty/partial list + degradation metric (circuit-breaker cooldown); hedge (re-issue) stragglers at p95_c x 1.5 only if idempotent and budget allows; total budget proposal: scatter<=120ms, fuse<1ms, rerank share per program lanes.
- Quota policy: start uniform w_c = max(100, 3*k_final) (ES/OS-converged shape); switch to size-proportional (ReDDE-style) once per-corpus sizes/densities are known AND divergence >10x; always dedup by deterministic ID first.
