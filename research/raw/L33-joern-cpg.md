VERDICT: Joern is a candidate offline scheduled security and dataflow-evidence layer via bounded tools, not a hot-path indexer. Run pysrc2cpg as an isolated bounded-heap job with environment and vendor excludes, integrity-check METHOD_REF/REF edges, treat Python flows as review candidates until the frontend matures, and export CALL/DDG edges to a downstream graph-ranking pipeline. The cited evidence supports line-numbered source-to-sink paths and caller graphs; deployment-specific throughput, heap, and memory limits require local validation.
