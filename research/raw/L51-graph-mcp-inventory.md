## Verdict (≤3 lines)
Top pick: **falkordb-mcp (Rust)** as the tool-surface template to copy — structural read-only enforcement (engine-level RO_QUERY / EXPLAIN classification, never advisory), params-bound Cypher everywhere (graphiti's injection CVE proves why), hard row caps + truncated flags, `explain`-without-execute, and write tools that don't exist unless an env flag opts in. We should NOT adopt any of these wholesale (each drags in a DB service or cloud dep); instead wrap our existing graphifyy+tantivy+LanceDB+PPR fusion in a thin FastMCP stdio server exposing the converged minimal surface: `get_schema`, `search(hybrid,q,k,filters)`, `neighbors(node,k,hops)`, `explain/trace`, `status`, with namespace prefixes (neo4j-style), group_id scoping (graphiti-style), tiktoken-bounded responses (Labs-style). Governance lesson from Kuzu: pin engines with exit plans and keep adapters thin — the archived-kuzu ecosystem shows vendor death strands MCP clients within months; prefer MIT/Apache deps (avoid neo4j/mcp's GPL-3.0 for code reuse).

## Tool-surface design lessons (distilled)
1. Enforce read-only structurally (GRAPH.RO_QUERY, EXPLAIN classification) — model compliance is never trusted (falkordb-mcp, neo4j/mcp, mcp-memgraph keyword blocklist as weaker variant).
2. Writes = separate tools, hidden until operator env-flag (FALKORDB_MCP_ALLOW_WRITES=1) — not just a mode switch.
3. All queries take `params` bind-object; never splice values into Cypher (all vendors post-2025; graphiti CVE fix release).
4. Every result channel bounded: row `limit`/max_rows + boolean `truncated`; token-limit truncation (tiktoken); read-query timeouts (30s default).
5. Schema-first orientation workflow baked into docs/prompts: list graphs → get_schema → per-label/type sampled property schemas (report sampledCount) → query (FalkorDB Node server).
6. Sampling knobs on schema introspection (default N per label, -1 = full scan) keep large-graph introspection cheap (mcp-neo4j-cypher).
7. `explain` (plan w/o execution) and gated `profile` let the agent self-diagnose missing indexes (falkordb-mcp).
8. Multi-instance hygiene: tool-name namespaces (neo4j Labs), group_id scoping (graphiti), JWT-tenant→database routing (memgraph).
9. Structured DTOs for nodes/edges ({id, labels, properties}) — predictable JSON beats prose dumps.
10. Ship client-facing prompt guidance alongside tools (memgraph PROMPT.md; kuzu generateKuzuCypher prompt) and a `get_status` health tool (graphiti).
11. Vector search belongs in the graph MCP surface when the engine has it (memgraph search_node_vectors) — mirrors our LanceDB layer being reachable through one tool surface.
12. Vendor-death resilience: archived upstream (kuzu) froze its MCP instantly; successors (LadybugDB) had no MCP parity at first — keep our wrapper DB-agnostic behind one interface.
