## Verdict
Top pick: **core `tree-sitter==0.25.2`–`0.26.0` + `tree-sitter-language-pack~=1.13` for all 9 grammars, driven by our own extended tags.scm** — single abi3 wheel install (zero compile on py3.13, offline, MIT), removes 9-package version juggling, and isolates us from the one real hazard (stale TS/TSX grammar + JSX-generic ERROR nodes). Integration sketch: add `tree-sitter>=0.25.2,<0.27` + `tree-sitter-language-pack~=1.13`; register tsx≠typescript and markdown+markdown_inline pairs; extract symbols with QueryCursor over per-lang tags.scm; enforce extractor rules: ignore root has_error (harvest inside ERROR), synthesize @Observable members for Swift, route *.jsonc to jsonc grammar; defer stack-graphs (404'd upstream). Watch item: TS grammar staleness (last real release Nov 2024) is the weakest link if our TS repos lean on newest TS syntax.

## Known gaps/bugs directly affecting OUR symbol extraction
1. **TSX generic-arrow ambiguity** (highest impact): `const f = <T>(x: T) => …` competes with JSX element syntax; ERROR-node recovery can detach `arrow_function`/`type_parameters`. Mitigations: parse .tsx ONLY with tsx grammar; accept both `<T,…>` forms; extractor harvests named nodes regardless of root error state; optionally pre-flag files with high ERROR density for regex fallback.
2. **Swift macro semantics**: `@Observable` (and any attached macros) expand at compile time only — tree shows an `attribute`; synthesized conformances/members absent → member-level graph nodes for such classes are systematically incomplete. Synthesize virtual members in graph builder keyed on attribute presence.
3. **Markdown injections need dual parsers**: block+inline split; forgetting `markdown_inline` silently degrades inline spans, and injected-language extraction inside fenced blocks additionally requires the target language parser loaded plus injection query application.
4. **JSON strictness**: JSONC (comments/trailing commas) errors out — needs separate jsonc grammar for config files.
5. **Core-binding API break (0.26)**: `Language.query()` removed → `Query(lang, src)`; `Language.version` → `abi_version`; timeouts → progress_callback. Any glue written against ≤0.24 tutorials breaks; graphifyy==0.9.16 does not declare tree-sitter today, so pin BEFORE writing glue.
6. **Python 3.13 status: GREEN** — cp313 wheels ship for every relevant package (core 0.25.1+/0.26.0 verified on PyPI; language-pack via cp310-abi3). Only red flag: no free-threaded (cp313t) wheels anywhere in the chain.
